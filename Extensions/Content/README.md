# Simflex\Extensions\Content\Content

Класс `Content` расширяет базовый компонент `ComponentBase` и предназначен для вывода контента на странице сайта. Он использует функциональность фреймворка Simflex для работы с контентом, включая получение данных из базы данных и их последующую обработку.

## Методы

### `get($path = ''): ?ModelContent`

Получает контент по заданному пути. Если путь не указан, используется текущий путь запроса. Возвращает экземпляр `ModelContent` или `null`, если контент не найден.

### `getStatic($alias)`

Статический метод для получения контента по алиасу. Возвращает данные контента, если они найдены, иначе `null`.

### `getTableFrom(string $param, $from): array`

Возвращает данные из таблицы в виде массива, основываясь на параметре и источнике данных.

### `getChildrenById(int $id, int $except = 0, string $sort = 'title ASC'): array`

Получает дочерние элементы контента по идентификатору родителя. Исключает элемент с указанным идентификатором `except`, если он задан. Сортирует результаты по указанному критерию.

### `getChildrenSorted(int $id, string $sort, int $except = 0): array`

Получает и сортирует дочерние элементы контента по заданному критерию сортировки.

### `getChildrenByPath(string $path): array`

Получает дочерние элементы контента по пути.

### `getChildrenConditional(string $path, array $cond): array`

Получает дочерние элементы контента, соответствующие заданным условиям.

### `getChildren(string $path, int $max = 10, array $s = [], int $ignore = 0): array`

Получает дочерние элементы контента, соответствующие заданным критериям поиска. Ограничивает количество результатов до указанного максимума.

### `content()`

Основной метод для вывода контента. Управляет логикой отображения контента, включая обработку пути запроса, генерацию хлебных крошек и подготовку данных для шаблона.

### `breadcrumbs($content)`

Генерирует хлебные крошки для текущего контента.

### `findTemplateFile(string $name): string`

Находит файл шаблона по имени. Возвращает путь к файлу шаблона.
